# Retail Sales Analysis

Este proyecto analiza las ventas de una tienda de retail usando NumPy y Python.

## Descripción
Análisis de datos de ventas por categoría (Beauty, Clothing, Electronics) 
para identificar totales, promedios y tendencias.

## Estructura del Proyecto
- `data/`: Archivos de datos CSV
- `notebooks/`: Notebooks de Jupyter
- `src/`: Código fuente
- `README.md`: Este archivo

## Instalación
1. Clona el repositorio: `git clone https://github.com/mpazriv/retail-sales-analysis.git`
2. Instala dependencias: `pip3 install numpy pandas`

## Uso
Ejecuta los notebooks en la carpeta `notebooks/` para ver el análisis.
